# CUA-S1 Forge

Verifier-driven fine-tuning research for the small CUA-S1 form-action scorer.

This repository is the experimental layer around the upstream CUA-S1 implementation. The first milestone is a reproducible Google Colab T4 smoke run that adds a verifier-sampled policy-gradient objective with entropy control, a KL anchor to the supervised baseline, and a small supervised stabilizer.

The term RLCD here is a generic label for this local verifier-driven objective. It is not a claim to reproduce any private TypeSafe or Jev training implementation. The training signal is generated by the local deterministic CUA-S1 verifier and synthetic form episodes only. Jev, TypeSafe Services, restricted outputs, and private teacher data are not used.

## Scope

CUA-S1 Forge is deliberately narrow: one-step form-action scoring over candidate options. It is not an autonomous browser agent and it does not execute live actions. Evaluation should use an untouched test split and report top-1 accuracy, NLL, calibration, coverage, selective accuracy, wrong-action rate, wrong-target rate, and unsafe-action rate where applicable.

A meaningful claim such as 100x better must name a denominator and metric first. This project makes no universal improvement claim until a controlled benchmark demonstrates one.

## Reproducibility

- Upstream source is pinned in the Colab run to commit 27a318c3a616f9ff19d24fe2acca7517c5f8fa7b.
- Synthetic splits are generated with a fixed seed and form-signature split.
- Generated data, checkpoints, and run logs stay outside the public Git history by default.
- Credentials are read from Colab Secrets and are never written to files or printed.

## Colab quickstart

The notebook should add the upstream and Forge source roots to sys.path, generate a deterministic synthetic split, run the upstream supervised baseline, run the verifier-driven fine-tune, and evaluate both models on the untouched test split.

The intended hardware target for the first smoke run is a single NVIDIA T4 with approximately 16 GB VRAM.
